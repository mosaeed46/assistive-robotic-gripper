# Prototype Testing

## Final results

| Test | Result |
| --- | --- |
| Closing time | 4.55, 4.53, 3.88, and 3.81 s; mean 4.19 s |
| Total mass | 150.2 g |
| Hand-mounted assembly mass | 85.4 g |
| Hand-mounted dimensions | 129.2 × 65.0 × 51 mm |
| Successful object diameters | 15.7–36.5 mm |
| Highest tested held mass | 50.0 g |
| Comfort ratings | 7.5, 8.0, 8.2, and 9.0 out of 10 |
| Drop durability | No visible damage after tests up to 2.67 m without electronics |

## Design changes informed by testing

- Replaced the original breadboard with a smaller unit, reducing total mass by 42.5%.
- Added an adjustable strap to improve fit and comfort.
- Added high-friction contact material to reduce object slipping.
- Refined the servo timing and added an intermediate stop state.
- Investigated scoop geometry to improve pickup from flat surfaces.

## Future development

- Add position or force feedback for closed-loop grip control.
- Improve geometry for thin objects.
- Complete higher-load testing with calibrated instrumentation.
- Reduce the electronics enclosure using a smaller microcontroller or custom PCB.
